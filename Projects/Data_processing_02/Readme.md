A command-line Python project that allows users to process:
- CSV files with pandas (filtering, normalization, stats)
- Images with PIL and numpy (editing, histogram, rotate)

## Features

 1. Tabular Data Processing  
 2. Image Processing  
 3. Histogram Visualization  
 4. Normalization & Querying  
 5. Save outputs to file  

## Requirements

- Python 3.7+  
- pandas  
- numpy  
- pillow  
- matplotlib  

### Install Dependencies

pip install pandas numpy pillow matplotlib
